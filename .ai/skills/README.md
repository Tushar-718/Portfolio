# AI Skills & Rules Directory

This directory (`.ai/skills`) acts as the "brain" for AI coding assistants working in this repository. 

Whenever you start a new session, the AI will reference these files to understand custom commands (like `/pr-review`) and project-specific rules (like formatting with `yarn check-all`).

### Files Included:
- **`pr-review.md`**: Defines the workflow for the `/pr-review` command.
- **`pr-review-validator.md`**: Defines the workflow for the `/pr-review-validator` command to verify fixes and post status updates.
- **`project-rules.md`**: Defines coding standards, linting expectations, and architectural best practices for this project.

*Feel free to add more `.md` files here whenever you want the AI to learn a new skill or follow a new rule across all future chat sessions!*
